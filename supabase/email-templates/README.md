# Supabase Auth email templates

Paste each file into **Authentication → Emails → Templates** in Supabase (the subject goes in the Subject field).

| Template in Supabase | File | Subject |
|---|---|---|
| Confirm signup | `confirm-signup.html` | Confirm your email for Compass |
| Reset password | `reset-password.html` | Reset your Compass password |
| Change email address | `change-email.html` | Confirm your new email for Compass |
| Magic link | `magic-link.html` | Your Compass sign-in link |
| Invite user | `invite.html` | You're invited to Compass |
| Reauthentication | `reauthentication.html` | Your Compass confirmation code |
